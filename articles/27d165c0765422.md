# 数値の処理やリストを効率的に扱える Numpy を使用してみる

Numpy は数学的処理(代数や乱数)やリスト処理(多次元)を得意とするパッケージです。

## Numpy の使い方

前回の項で、環境開発が完了していると思います。
新規ファイルを作成し、配列を作っていきます。

```python
import numpy as np

one_dimension = np.array([1, 2, 3])

one_dimension
# array([1, 2, 3])
```

実際に出力してみると、通常のリストと違うことがわかります。
Numpy では、ndArray オブジェクトが作成され、今回でいうと 1 次元 3 要素のデータが作成されています。
type を実施することで、実際に Numpy が保持しているデータ型になっていることもわかるかと思います。

```python
type(one_dimension)

# numpy.ndarray
```

何次元のデータなのかを

```python
one_dimension.shape

# (3,)
```
