# Python の環境構築を作ってみよう

Mac に Python が入っていることを前提に進めます（Windows でも概ね同じ）。
Rust 製の uv や conda でも仮想環境を作れますが、この記事では試験範囲にも含まれる標準の `venv` に絞り、パッケージを分離した状態で JupyterLab が使えるところまでをまとめます。

## 仮想環境 venv とは

仮想環境 `venv` は、プロジェクトごとに独立した Python 実行環境を作る仕組みです。
ローカル環境に直接パッケージを入れるとプロジェクト間でバージョン衝突が起こりやすいですが、
`venv` を使えば依存関係を完全に分離でき、安全に管理できます。

### 導入するメリット

- 標準機能だけでプロジェクトごとに独立した Python 環境を用意できる。
- 依存パッケージをプロジェクト単位で分離でき、他プロジェクトと衝突しない。
- `requirements.txt` で依存を共有・再現しやすい。
- フォルダを削除するだけでクリーンアップでき、試行錯誤がしやすい。
- pyenv と併用すればプロジェクトごとに Python バージョンも切り替えられる。

## venv で仮想環境を作る

例としてカレントディレクトリに `.venv` という名前で作成します。任意の名前で OK です。

```zsh
python -m venv .venv
```

できあがるディレクトリ構成：

```zsh
tree -a -L 2
.
└── .venv
    ├── .gitignore
    ├── bin
    ├── include
    ├── lib
    └── pyvenv.cfg
```

## 仮想環境の使い方

作っただけでは仮想環境が使えるわけではないため、必要に応じて環境を有効／解除します。
もう使わない場合は `.venv` フォルダごと削除して問題ありません。

:::message
`pip install` などのパッケージ追加は、必ず環境をアクティブにしてから行う。
そうでないとローカルにインストールされてしまう。
:::

環境をアクティブにする:

```zsh
source .venv/bin/activate
```

環境を非アクティブにする:

```zsh
deactivate
```

## 環境が分離できているか確認

ローカル環境（未 activate）:

```zsh
which pip
/Users/xxxxxx/.pyenv/shims/pip
```

venv 環境（activate 済み）:

```zsh
which pip
/Users/xxxxxx/test_venv/.venv/bin/pip
```

pip の指先が違い、実際にローカルと venv 上分離できていることがわかります。

## 必要なパッケージを導入する

この後のデータ分析で最低限使うパッケージ例を `requirements.txt` にまとめて入れます。

```requirements.txt
numpy==2.3.5
pandas==2.3.3
matplotlib==3.10
scikit-learn==1.7.2
jupyterlab==4.5.0
openpyxl==3.1.5
html5lib==1.1
```

仮想環境をアクティブにした状態でインストール:

```zsh
pip install -r requirements.txt
```

## JupyterLab の使い方

JupyterLab は Web ブラウザ上でノートブックを編集・実行できる環境です。データ可視化やプロトタイピングに向いています。

JupyterLab を起動:

```zsh
jupyter lab
```

ポートを指定したい場合:

```zsh
jupyter lab --port=8080
```

起動させるとブラウザに Jupyter Lab が開きます。
開かない場合は`http://localhost:8888/`(デフォルト)へアクセスしてください。

### パッケージが利用できるか確認する

画像の通り、ご自身が作成しているプロジェクトの Notebook を開き、次のセルを実行してインポートとバージョンを確認します。

![](/images/jupyter-lab.png)
_初期画面_

適当にディレクトリ/ファイルを作成し、以下のスニペットを実行します。

```python
import html5lib
import matplotlib as plt
import numpy as np
import openpyxl
import pandas as pd
import sklearn as sl

versions = {
    "html5lib": html5lib.__version__,
    "matplotlib": plt.__version__,
    "numpy": np.__version__,
    "openpyxl": openpyxl.__version__,
    "pandas": pd.__version__,
    "sklearn": sl.__version__,
}

print("\n".join(f"{k}={v}" for k, v in versions.items()))
```

![](/images/check-version.png)
_実行後の状態_

もし、確認が取れなかったときはパッケージのインストールが venv 上なのか、ローカル上なのか確認をしていきましょう!

## 終わりに

標準の `venv` だけでも十分に環境分離でき、インストールも簡単です。
以降の開発や検証はこの環境を前提に進めるので、手元で `.venv` を用意しておくとスムーズに追従できます。
